# ArmStarter — тренажёр старта для армрестлинга

Веб-страница, которая голосом рефери (английские команды) даёт старт, а встроенная
камера ловит момент, когда ты дёрнул рукой, и считает **время реакции** в миллисекундах.
Плюс ловит **фальстарт** — движение раньше команды.

## Три типа команд (выбираются случайно)
- **Go** — просто команда, без предупреждения.
- **Ready … пауза … Go** — пауза случайная, нельзя угадать.
- **Ready-Go** — слитно, быстро.

Перед каждой командой есть «окно тишины» случайной длины: дёрнулся в это время — **фальстарт**.

## Запуск на Mac (камера ноутбука)
1. Двойной клик по **`start-mac.command`**.
2. Откроется браузер, разреши доступ к камере.
3. Поставь руку в зелёную рамку, держи неподвижно → **Калибровать порог** → **Старт**.

> Если macOS ругается «неизвестный разработчик»: правый клик по файлу → «Открыть» → «Открыть».

## Запуск на iPhone (камера телефона)
Камере в Safari нужен **HTTPS**, с локального файла она не включится. Варианты:

- **GitHub Pages (бесплатно):** залей `index.html` в репозиторий → Settings → Pages →
  включи Pages → открой выданную `https://…`-ссылку в Safari.
- **Быстро через ngrok:** на Mac запусти `start-mac.command`, в другом окне терминала
  `ngrok http 8123` → открой выданную `https://…`-ссылку на iPhone.

Пропусти телефон в горизонтальной подставке так, чтобы рука была в кадре.

## Настройки
- **Пауза между повторами** — сколько ждать перед следующей командой.
- **Окно перед «Go»** — диапазон случайной задержки (зона фальстарта). Шире = труднее угадать.
- **Типы команд** — галочки.
- **Чувствительность** и **размер рамки** — под свет и под то, как близко рука к камере.
  Кнопка **Калибровать** замеряет шум при неподвижной руке и подстраивает порог.

## Точность
Отсчёт реакции ограничен частотой кадров камеры (~16–33 мс) и небольшой задержкой
синтеза речи. Цифры стабильны и хорошо сравнимы между повторами, но это не лабораторный
таймер — это тренажёр для наработки взрывного старта и выдержки.
